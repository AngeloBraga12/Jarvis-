# Security Policy

## Supported version

The current `main` branch is the supported development line.

## Reporting a vulnerability

Do not publish exploit details in a public issue. Report security problems privately through GitHub's repository security features when available.

Include the affected component, reproduction steps, impact and any relevant logs with secrets removed.

## Security expectations

JARVIS is an assistant that may eventually control local resources. Security-sensitive changes require tests and documentation before the capability is enabled.
